# Credit_Card_Portfolio_Performance_Dashboard

## Project Overview
This project analyzes credit card portfolio performance to monitor key metrics such as revenue growth, delinquency rate, and customer activity.

## Business Problem
Financial institutions need better visibility into portfolio performance to identify growth opportunities and manage credit risk.

## Objectives
- Track key performance indicators (KPIs)
- Identify high-risk customer segments
- Analyze portfolio growth trends

## Tools Used
- SQL
- Power BI
- Excel

## Key KPIs
- Revenue
- Active customers
- Delinquency rate
- Month-over-month growth

## Dashboard Features
- Interactive filters
- Drill-down analysis
- KPI cards
- Trend analysis

## Insights
- Delinquency rate increased by 6% in Q3.
- High-value customers contribute 48% of total revenue.
- Region X shows the highest growth potential.

- dashboard → Power BI project
- dataset → sample dataset
- sql_queries → SQL used for analysis
