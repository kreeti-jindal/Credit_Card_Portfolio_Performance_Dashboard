# Credit Card Portfolio Performance Dashboard

## Project Objective
The objective of this project is to build an interactive Power BI dashboard to monitor credit card portfolio performance. 
The dashboard provides real-time insights into key metrics such as revenue, transactions, customer activity, and delinquency trends to support business decision making.

## Data Source
The dataset contains credit card transaction and customer information including:

- Customer demographics
- Transaction amount
- Interest earned
- Annual fees
- Credit card type
- Weekly transaction data

Data was imported into SQL tables and queried for analysis.

## Data Processing
1. Raw CSV files were imported into SQL database tables.
2. SQL queries were used to extract required data.
3. Data was imported into Power BI for visualization.
4. Power Query transformations were applied for cleaning and structuring the data.

## Dashboard Features

The dashboard provides:

- Weekly revenue analysis
- Transaction count and amount tracking
- Customer segmentation
- Credit card category performance
- Regional analysis
- Activation rate monitoring
- Delinquency rate monitoring

## Key KPIs
- Total Revenue
- Active customers
- Delinquency rate
- Weekly Revenue Growth
- Average Transaction Value
- Interest Earned

## Key Insights

- Weekly revenue increased by 28.8%.
- Total revenue reached 57M.
- Total interest earned is 8M.
- Total transaction amount is 46M.
- Male customers contribute 31M revenue compared to 26M from female customers.
- Blue and Silver credit cards contribute to 93% of transactions.
- TX, NY, and CA contribute to 68% of revenue.
- Overall activation rate is 57.5%.
- Delinquency rate is 6.06%.
